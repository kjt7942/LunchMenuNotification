# Execution Plans

에이전트가 작업을 수행하면서 계획하고 완료한 작업 내역을 관리하는 공간입니다.
다른 에이전트가 이어받아 작업할 때 중요한 맥락(Context) 소스가 됩니다.

## 구조 가이드
이 폴더는 차후 작업 볼륨이 늘어나면 `active/` (진행 중) 파일들과 `completed/` (완료됨) 폴더로 구획될 수 있습니다.
- 새로운 PR, 에픽 단위의 태스크 수행 시 여기에 `{Feature명}-plan.md`를 작성하고 업데이트합니다.
- 기술 부채 리스트업, 해결 기록 또한 이 공간의 파일들을 통해 로깅되어야 합니다.
