# Design Docs

이 디렉토리는 하네스 엔지니어링 시스템을 지탱하는 '핵심 신념', '설계 원칙', '아키텍처 가이드'를 관리합니다.
엔지니어의 의도(Intention)가 이곳에 명시되며, 에이전트는 코드 작성 전 이 원칙들을 먼저 준수해야 합니다.

## 1. 기반 철학 (Agent-First Principles)
1. **No Manual Coding**: 사람이 작성하는 코드는 없습니다. 코드는 에이전트가 생산하며, 사람은 환경 설계와 목표만을 정의합니다.
2. **Agent Readability**: 코드 구조, 변수명, 주석, 문서의 모든 형태는 사람이 읽기 편한 구조보다, 에이전트가 파싱하고 맥락을 파악하기 편한 기계 친화적(Structured, Explicit) 형태를 따릅니다.
3. **Immutable Logic & Cumulative Updates**: 검증을 통과해 안정화된 로직은 보호합니다. 파괴적인 리팩토링이나 롤백보다는 누적 업데이트(Append-Only / Extension 방식) 형태로 전진합니다.

## 2. 관리 규칙
- 변경 불가능한 코어 정책에 변경이 필요할 경우, 이곳에 사유가 먼저 서술 및 토론(리뷰 대상)되어야 합니다.
- 시스템 구성요소 관련 설계가 끝난 후, 각 컴포넌트별로 별도의 .md 파일로 나누어 정리될 수 있습니다.
